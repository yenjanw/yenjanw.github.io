# 臺灣個資管理制度整合圖：ISO 27701、TPIPAS、CBPR 的定位與整合路徑

一個框架、三種角色——企業隱私保護建置的策略選擇

---

台灣企業在規劃隱私管理系統時，往往面臨一個共同困惑：ISO 27701、TPIPAS、CBPR 三套制度究竟有何不同？該從哪一套開始？彼此能否整合？本文以系統化視角，解析三框架的定位差異、主管機關分工，以及企業實務整合路徑。

---

## 一、三框架基本定位

### ISO 27701：國際通用標準，PIMS 建置基石

ISO 27701:2025（ISO 27701:2019 之 2025 年修訂版）全名為「Privacy Information Management System — Extensions to ISO/IEC 27001 and ISO/IEC 27002 for PII Management」，是 ISO 家族中唯一針對隱私資訊管理制訂的國際標準。

其核心價值在於：
- 建立 PII（Personal Identifiable Information）管理系統的系統化框架
- 明確 PII Controller（個資控管者）與 PII Processor（個資處理者）之角色界分
- 要求組織進行 PIA（Privacy Impact Assessment，隱私影響評估）
- 可與 ISO 27001（資安管理系統）整合實施，共享風險評估與控制框架

ISO 27701 為**自願性認證標準**，無強制主管機關，企業可自行決定是否申請第三方驗證。

### TPIPAS：台灣產業認證制度，經濟部推動

TPIPAS（Taiwan Personal Information Protection and Administration System）是我國經濟部核可之個人資料管理系統驗證制度，由經濟部工業局主責，委託公正驗證機構執行驗證。

TPIPAS 的核心特徵：
- **強制性色彩**：政府補助案、科學園區廠商、上市櫃公司併購審查等情境，常被要求透過 TPIPAS 驗證
- **Block A–D 四構面**：涵蓋管理責任（A）、蒐集處理利用（B）、顧客权益保障（C）、持續改善（D）
- **文件化要求完整**：提供詳細稽核矩陣，適合做為企業內部管理系統建置藍圖
- **認證效期 3 年**：期滿須重新驗證

TPIPAS 與個資法的對應最為直接，其控制項設計大量參照個資法§5、§8、§20-1、§29 等條文，企業透過 TPIPAS 驗證，幾乎等同完成個資法主要合規義務。

### CBPR：APEC 跨境隱私規則，亞太資料流通護照

CBPR（Cross-Border Privacy Rules）系統為 APEC 框架下之跨境隱私處理機制，由美國主導，我國於 2012 年加入 APEC 時即同步參與 CBPR。

CBPR 的核心定位：
- **會員制**：參與經濟體（Economy）之企業可向經 APEC 認可之 Accountability Agent（問責代理機構）申請認證
- **跨境傳輸合規工具**：認證企業在 CBPR 會員經濟體間傳輸個人資料時，無需逐一取得當事人同意，簡化跨境合規流程
- **我國 Accountability Agent**：目前為 CNSEC（中華民國資訊安全學會），負責我國企業 CBPR 認證之受理與初審
- **與個資法§21 之互動**：個資法§21 規範國際傳輸許可機制（當事人同意或經主管機關許可），CBPR 認證可作為「經主管機關許可」之認定依據之一

## 二、主管機關分工：三軌並行的體制

三框架背後對應不同主管機關，形成複線治理結構：

| 框架 | 主管機關 | 體系歸屬 | 法律性質 |
| --- | --- | --- | --- |
| ISO 27701 | 無特定主管機關（自願性國際標準）| ISO 家族 | 自願性驗證 |
| TPIPAS | 經濟部工業局 | 台灣行政體系 | 產業認驗制度 |
| CBPR | 我國：國家通訊傳播委員會（NCC）╳ Accountability Agent | APEC 框架 | 跨境認證機制 |
| 個資法（本法）| 國家發展委員會（國發會）| 台灣法律 | 強制性法律 |

**重要提醒**：台灣個人資料保護委員會（PDPC）組織法仍卡關立法院（114-06-24 黨團協商後實質停滯），PDPC 尚未正式成立，裁罰新規（§48III，15-1500 萬）亦無從適用。目前個資法裁罰上限仍為§47 之 5-50 萬元。

## 三、三框架七面向比較表

| 面向 | ISO 27701 | TPIPAS | CBPR |
| --- | --- | --- | --- |
| **適用對象** | 全球任何處理 PII 之組織 | 台灣非公務機關（尤其企業）| 亞太區（APEC 會員經濟體）企業 |
| **主管機關** | 無（自願性標準）| 經濟部工業局 | NCC（我國）╳ APEC |
| **認證門檻** | ISO 27001 為先決條件；高匯入成本（數十至數百萬）| 須達一定規模（大型企業較適合）| 須透過 Accountability Agent 初審 |
| **跨境適用性** | 全球通用（與各國法規接軌）| 台灣境內 | APEC 21 個會員經濟體 |
| **核心焦點** | 隱私資訊管理系統建置 | 個資法合規驗證 | 跨境資料傳輸信任機制 |
| **與個資法對應** | 間接對應（通用框架）| 直接對應（控制項直接映射§5§8§20-1 等）| 對應§21 國際傳輸許可 |
| **整合難度** | 高（需先有 ISO 27001 基礎）| 中（文件體系完整）| 低（獨立申請，認證週期較短）|

## 四、企業適用情境：誰適合走哪條路徑？

### 初創或中小型企業（員工 < 50 人）

**推薦路徑**：先以個資法§20-1 安全維護義務為核心，建立基本隱私管理制度，待規模擴大再考慮 TPIPAS 或 ISO 27701。

可行做法：
- 依施行細則§12 十一項安全維護措施建立基本控制
- 完成個資清冊（ROPA）
- 指派隱私管理負責人員（ PDPO 設置草案通過後須達強制門檻）

### 上市櫃或大型企業（員工 ≧ 100 人，含集團子公司）

**推薦路徑**：以 TPIPAS 為核心框架，ISO 27701 為進階目標，兩者同步整合建置。

理由：
- TPIPAS Block A–D 與個資法條文高度對應，建置 TPIPAS 的同時即完成個資法合規
- ISO 27701 可與既有 ISO 27001 整合，降低額外匯入成本
- TPIPAS 認證可做為投標、政府補助申請、併購審查之合規證明

### 有跨境資料傳輸需求之企業（電商、科技、跨國製造）

**推薦路徑**：CBPR 認證為必備，輔以 TPIPAS 或 ISO 27701 強化內部管理。

情境分析：
- 電商平台處理 APEC 會員國消費者個資（尤其美國、日本、澳洲）
- 跨國製造或科技公司，子公司間調閱個資
- 雲端服務供應商處理跨國使用者資料

CBPR 認證完成後，配合個資法§21 許可機制，可大幅簡化合規負擔。

## 五、三框架整合可能性與實務做法

### ISO 27701 與 TPIPAS 之整合

ISO 27701 與 TPIPAS 之控制項高度重疊，企業可在建置 TPIPAS 時同步對齊 ISO 27701 要求：

| TPIPAS Block | ISO 27701 Cl. | 對應個資法條文 |
| --- | --- | --- |
| Block A（管理責任）| Cl.5（Leadership）| §20-1 |
| Block B（蒐集處理利用）| Cl.6（PII Controller obligations）| §5╳§8╳§15-19 |
| Block C（顧客权益保障）| Cl.6.4-6.7（PII subject rights）| §3（當事人權利）|
| Block D（持續改善）| Cl.9╳Cl.10（Monitoring╳Improvement）| §12XI（事故應變）|

兩者最大差異在於：ISO 27701 要求明確之 PII Controller╳Processor 角色界分，並對 Processor（如 SaaS 廠商）設定額外控制要求；TPIPAS 主要以個資控管者視角設計，適用於企業內部管理。

### TPIPAS╳CBPR 之整合

TPIPAS 與 CBPR 可先後申請，互不排斥：
1. 先透過 TPIPAS 建立完整個資管理系統
2. 再以 TPIPAS 既有文件為基礎，向 CNSEC 申請 CBPR 認證
3. CBPR 之 Privacy Policy╳Data Lifecycle Management╳Breach Notification 要求，與 TPIPAS Block C╳Block D 高度對應

此「TPIPAS 先行、CBPR 補充」之策略，可同時滿足國內外合規需求，並節省重複建置成本。

## 六、實務觀察：台灣企業隱私管理常見誤區

### 誤區一：透過 TPIPAS 認證等於完全合規

TPIPAS 驗證針對個資法核心義務設計，但仍有盲點：
- TPIPAS 不涵蓋特種個資（§6）之書面同意審查要求
- 產業別法（金融業金管會規範、醫療業衛福部規範）與 TPIPAS 控制項可能存在競合，須另行確認
- PDPC 子法（安全維護管理辦法╳事故通知通報及應變辦法）透過後，TPIPAS 內容須同步更新

### 誤區二：ISO 27001 認證自動涵蓋隱私管理

ISO 27001 為資安管理系統標準，與隱私管理系統之焦點不同：
- ISO 27001 聚焦資訊資產之機密性、完整性、可用性
- ISO 27701 才針對 PII 之蒐集、處理、留存、傳輸、删除設定專屬控制
- 企業若僅透過 ISO 27001，未必能滿足個資法§20-1 安全維護義務之完整要求

### 誤區三：CBPR 認證可替代國內個資法§21 許可

CBPR 認證為跨境資料傳輸提供「企業問責」機制，但：
- 個資法§21 之國際傳輸許可，仍須依個資法規定程序辦理
- CBPR 認證可作為「已建立個資保護制度」之認定參考，但不等同自動免除§21 義務
- 建議企業同時檢視「各目的地國家之資料當地化要求」（如中國、越南均有資料境內儲存要求）

### 誤區四：PDPC 尚未成立，無需積極整備

PDPC 組織法立法腳步雖緩，但：
- §48III（15-1500 萬裁罰區間）一旦適用，無預警期
- 安全維護管理辦法草案已明定「保有個資 1 萬筆以上」之大型非公務機關須適用強化措施
- 新加坡 PDPC 2026 年首月四案連發，已顯示亞太區監理加速趨勢

## 七、企業選擇建議流程圖

```
開始
  │
  ▼
企業是否處理跨國個資（APEC會員國使用者）？
  │
  ├─ 是 → CBPR 認證是否已有或規劃中？
  │         │
  │         ├─ 否 → 優先申請 CBPR（認證週期較短，跨境效益立即）
  │         └─ 是 → CBPR 已取得，檢視 TPIPAS╳ISO 27701 需求
  │
  └─ 否 → 企業規模與產業特性？
            │
            ├─ 上市櫃╳大型企業 → TPIPAS 為核心，ISO 27701 為進階
            │
            ├─ 中小企業 → 先建立§20-1 基礎合規，評估 TPIPAS 需求
            │
            └─ 有 ISO 27001 基礎 → ISO 27701 擴充整合（最具效率）
            │
            ▼
            是否需要做為投標╳補助╳併購審查之用？
              │
              ├─ 是 → TPIPAS（最具公信力）
              └─ 否 → 內部管理需求優先 → ISO 27701（國際通用）

結束
```

## 八、結語

ISO 27701、TPIPAS、CBPR 三框架各有定位，彼此並非互斥，而是可以在企業內部隱私管理系統中形成互補。

- **TPIPAS** 是最適合台灣企業的個資法合規工具，其控制項與個資法條文高度對應
- **ISO 27701** 是邁向國際標準、提升管理系統成熟度的進階選擇
- **CBPR** 是處理亞太跨境資料時，不可或缺的合規護照

企業不必一次到位，可根據自身規模、產業特性與業務需求，選擇最適合的進入路徑。重點是：開始建立隱私管理系統的過程本身，即是降低合規風險的最有效行動。
