# ISO/IEC 27701:2025 驗證機構怎麼選：企業不能只看證書和品牌

企業準備導入 ISO/IEC 27701，常見的採購流程是先列出幾家知名驗證機構，再比較報價、稽核人天和證書樣式。這些資訊當然有用，但還不夠。真正需要先確認的問題是：這家機構是否在正確的認證範圍內，有能力依隱私資訊管理系統的要求執行查證？稽核團隊是否理解企業實際處理的個人資料？最後拿到的證書，能不能讓客戶、供應商或管理階層清楚知道它代表什麼？

2025 年公布的 ISO/IEC 27706:2025，正好把注意力拉回驗證機構本身。這份標準的對象不是準備受驗證的企業，而是提供隱私資訊管理系統稽核與驗證的機構。企業如果只研究 ISO/IEC 27701 的控制要求，卻沒有查驗驗證機構的資格與能力，最後可能完成了一次形式上的稽核，卻沒有建立足夠可信的外部保證。

本文的切入點不是重新整理 ISO/IEC 27701 的全部條文，而是處理一個採購現場更常遇到的問題：企業應如何判斷候選驗證機構，以及如何把選機構的決策留下可稽核的證據。

## 一、先分清楚三個容易混在一起的角色

企業、驗證機構與認證機構在制度中的責任不同。企業負責建立、執行和持續改善自己的隱私資訊管理系統；驗證機構負責依適用標準對企業進行稽核並作出驗證決定；認證機構則評估驗證機構是否具備執行特定驗證方案的能力。

這三者的關係可以簡化如下：

| 角色 | 主要工作 | 企業要查的證據 |
| --- | --- | --- |
| 受驗證企業 | 建立並維持 PIMS，管理個人資料處理風險 | 適用範圍、處理活動、控制措施與改善紀錄 |
| 驗證機構 | 執行稽核、審查證據並作成驗證決定 | 認證編號、認證範圍、驗證方案與稽核團隊能力 |
| 認證機構 | 評估驗證機構是否有能力執行該方案 | 公開名錄、認證證書、範圍文件與有效期間 |

企業取得 ISO/IEC 27701 證書，不代表企業本身取得了 ISO/IEC 27706 證書。ISO/IEC 27706:2025 的規範對象是驗證機構，它用來確保驗證機構在執行 PIMS 稽核時具備一致、可靠且符合隱私專業需求的能力。這個基本區分若沒有先講清楚，採購文件很容易把企業驗證標準、驗證機構資格和認證機構評鑑混成一件事。

## 二、ISO/IEC 27706:2025 對企業採購有什麼實際影響

ISO 官方資料顯示，ISO/IEC 27706:2025 於 2025 年 10 月發布，取代先前的 ISO/IEC TS 27006-2:2021。新版架構改以 ISO/IEC 17021-1 的管理系統驗證要求為基礎，並增加驗證文件、PIMS 專業能力及稽核時間計算等內容。

企業不必把這份標準當成另一套要自行取得的管理系統標準，但可以把它轉成三項供應商查核問題。

第一，候選驗證機構的認證範圍是否確實涵蓋 PIMS。不能只看到母公司網站寫著可以提供 ISO/IEC 27701 驗證，就推定台灣執行稽核的分支機構也具有相同資格。企業應要求對方提供認證機構的公開名錄連結、認證編號、適用標準版本、業務範圍和證書有效期間。

第二，稽核團隊是否具備隱私專業能力。PIMS 稽核不只是確認文件有沒有編號，也不只是沿用資訊安全管理系統的訪談清單。稽核人員要能理解個資蒐集、利用、委外、當事人權利、資料保存、刪除、跨境傳輸和事件應變之間的關係。企業可以要求候選機構說明稽核員如何分工、如何確認 PII 控制者和 PII 處理者角色，以及遇到跨法域資料流時如何判斷稽核證據。

第三，稽核人天與範圍是否有合理依據。企業資料處理活動越多、角色越複雜、據點越分散，稽核所需的抽樣和訪談通常也會增加。若供應商只用固定低價吸引簽約，卻沒有說明範圍、控制者與處理者角色、主要處理活動及多據點安排，後續很可能出現稽核範圍縮小、追加費用或證書內容與內部期待不一致的問題。

## 三、台灣企業選擇驗證機構時，至少要查六件事

### 1. 認證範圍，而不是品牌知名度

先查認證機構公開資料，再看驗證機構的行銷資料。企業要確認的不是「這家公司有沒有做過 ISO 27701」，而是「執行本案的法人或分支機構，是否在有效認證範圍內提供這項驗證」。若對方只提供海外母公司證書，企業應把它標記為海外資格，不能直接當成台灣在地認證範圍的替代證據。

採購紀錄至少應保存查詢日期、認證機構名稱、驗證機構名稱、認證編號、適用標準、範圍文字和有效期限。這些資料未來可能因標準改版、認證範圍調整或證書換發而改變，不能只把當時看到的網頁網址貼在比較表裡。

### 2. 採用的標準版本

ISO/IEC 27701:2025 與 ISO/IEC 27706:2025 的版本變化，會影響企業的轉版規劃、驗證方案和稽核準備。企業應要求驗證機構在報價與驗證計畫中明確寫出採用版本，以及目前是初次驗證、轉版、追查還是更新驗證。

尤其要避免用「新版已經可以做」這種模糊說法取代書面確認。採購人員應問清楚：本次驗證適用哪一份標準？哪些控制項會納入稽核？舊版文件是否可以暫時沿用？若制度尚在轉版，缺口會如何分類與追蹤？

### 3. PIMS 專業能力如何被證明

要求驗證機構說明稽核團隊的 PIMS 經驗，不等於要求提供個人履歷中的所有資料。比較有用的問法，是請對方具體說明團隊如何處理以下情境：

- 同一企業同時扮演個資控制者與受託處理者。
- 委外服務商使用子處理者，且資料儲存在不同國家。
- 企業保存的是原始資料、特徵模板、分析結果或去識別化資料。
- 當事人權利流程與客服、身分驗證及資料刪除系統相互連動。
- 事故紀錄已完成技術處置，但通知、通報或證據保存仍在判斷中。

好的驗證計畫應能把這些實際處理活動連回風險評估和控制證據，而不是只列出幾個政策文件名稱。

### 4. 稽核時間與抽樣邏輯

TAF 公開的標準改版文件指出，新版 PIMS 驗證方案包含 PIMS 專業能力、驗證文件內容與稽核時間計算等重點。企業應請驗證機構說明人天估算的基礎，包括組織規模、處理活動數量、控制者與處理者角色、據點、資訊系統和委外關係。

如果企業有多個品牌、不同業務線或跨國服務，不能只用員工人數估算 PIMS 稽核複雜度。稽核時間過短，可能讓重要資料流和實際作業沒有被抽到；時間過長但沒有清楚的抽樣邏輯，則會使內部難以判斷支出是否合理。企業應將人天計算說明和最終驗證範圍一起歸檔。

### 5. 證書與驗證文件寫得是否足夠清楚

企業應在簽約前先看一份去識別化的證書範例，確認證書是否會清楚描述組織、地點、服務範圍及 PIMS 適用邊界。若企業希望把證書提供給客戶或納入供應商資格審查，也要先確認對外文件能否避免過度宣稱。

ISO/IEC 27701 驗證不等於所有個資法義務都已自動完成，也不等於所有產品、子公司和供應商都被涵蓋。證書的適用範圍若寫得過於寬泛，反而會讓外部利害關係人誤以為整個集團或所有資料處理活動都已經受查核。

### 6. 查核後的異常處理與持續監督

不要只問初次驗證能否通過，也要問不符合事項如何分級、矯正期限如何計算、追查驗證如何安排，以及重大組織或處理活動變更是否需要重新評估。企業新增雲端服務、改用新的子處理者、進入新的法域，或把客服資料接到 AI 分析工具，都可能影響原有 PIMS 範圍。

驗證機構的角色是提供獨立查核，不是替企業撰寫制度或保證未來不會發生個資事件。若同一供應商同時提供顧問與驗證服務，企業更應在合約與內部採購紀錄中區分兩種角色，避免獨立性受到質疑。

## 四、不要把 TPIPAS、ISO/IEC 27701 和法定合規混成同一張證書

台灣企業常同時接觸個資法、TPIPAS 和 ISO/IEC 27701。三者可以互相支援，但用途不同。個資法是法定義務來源；TPIPAS 是台灣個資保護與管理制度的驗證及管理架構；ISO/IEC 27701 則提供國際化的隱私資訊管理系統架構與驗證路徑。

企業如果要同時準備多套要求，應建立控制對照表，但不能因此宣稱取得其中一項就自動滿足另外兩項。比較穩妥的做法，是把每一項外部要求分開記錄：適用對象、證據要求、驗證或稽核方式、版本、有效期間和未涵蓋範圍。

TPIPAS 官方文件頁面同時提供制度文件、申請文件、實務指引及修正草案。文件已經上架，不代表每一份內容都具有相同的規範效力。企業在準備驗證前，應請驗證機構以書面確認本次採用的制度版本、附表版本、申請文件和轉版安排，不要只依搜尋結果找到的第一份 PDF 作業。

## 五、給管理階層的一份最小採購檢核表

若企業現在就要啟動採購，可以先要求候選驗證機構回答以下問題，並將答案連同附件保存：

| 檢核項目 | 最少要取得的資料 |
| --- | --- |
| 認證資格 | 認證機構名錄連結、認證編號、範圍、有效期間 |
| 標準版本 | ISO/IEC 27701 與 ISO/IEC 27706 採用版本、轉版說明 |
| 團隊能力 | 稽核員角色、PIMS 專業能力與相關產業經驗說明 |
| 稽核規劃 | 範圍、據點、抽樣方式、人天估算與稽核階段 |
| 驗證文件 | 證書範例、適用範圍描述、公開驗證資訊方式 |
| 獨立性 | 顧問與驗證角色區分、不符合事項處理及申訴機制 |
| 持續監督 | 追查、更新、重大變更和暫停或撤銷驗證的處理方式 |

管理階層要批准的，不應只有一個最低報價，而是一個有證據支持的選擇。若某家機構價格較低，企業應先確認是因為資料範圍較小、據點較少、抽樣方式不同，還是只是把必要工作留到後續追加。只有把差異問清楚，價格比較才有意義。

## 六、結論：先確認誰有資格查，再準備自己要被查什麼

ISO/IEC 27701 驗證的價值，不在於多一張可以放在網站上的證書，而在於外部查核能否對企業的個人資料處理活動提出可信的獨立判斷。ISO/IEC 27706:2025 把驗證機構的能力、文件和一致性要求說得更清楚，也提醒企業不要只看品牌、報價或過往案例。

實務上，企業可以先做三件事：確認執行本案的法人與認證範圍，取得稽核團隊 PIMS 專業能力的具體說明，並把驗證範圍、人天邏輯、證書內容及持續監督條件寫入採購與合約文件。接著再檢查自己的資料清冊、處理活動、委外關係、當事人權利和事故應變證據是否真的能支撐稽核。

這樣選出來的驗證機構，才不只是能開證書的供應商，而是能對企業隱私治理提出有用外部檢查的獨立第三方。
